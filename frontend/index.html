Exercicis amb tutor

Tria un exercici de les llistes i explica què has fet, o fes una foto de la llibreta. El tutor et guia amb preguntes i pistes graduades, sense donar-te la solució.

Entrar → ≠

Troba l'error

Un resultat dels apunts o la resolució d'un problema amb errors amagats. Marca'ls sobre el text, explica per què són incorrectes i compara amb la correcció.

Entrar → ∃

Cert o fals

Afirmacions que semblen certes i potser no ho són. Decideix si són certes o falses i justifica-ho amb una demostració o un contraexemple.

Entrar → ∄

Construeix el contraexemple

Escriu una funció amb propietats que semblen incompatibles (parcials sense continuïtat, el mateix límit per totes les rectes però sense límit) i el certificat que ho prova. Ho comprova el càlcul simbòlic, sense IA.

Com funciona el tutor

Cada missatge passa per quatre etapes. El model de llenguatge només llegeix i redacta; què es pot dir ho decideixen regles fixes.

  1. 1

    Diagnosi

    Compara el que has escrit amb la solució de referència: quins passos has fet, quins errors hi ha, com d'encallat estàs.

    Model de llenguatge
  2. 2

    Pla

    Unes regles decideixen què fer: qüestionar un error, validar i avançar, o donar una pista del nivell que toca.

    Regles fixes
  3. 3

    Redacció

    El redactor només veu el contingut permès: ni els passos següents ni el resultat. No pot filtrar el que no sap.

    Model de llenguatge
  4. 4

    Guardià

    Abans d'arribar-te, el missatge es revisa: si revela massa o conté un error, es reescriu.

    Regles i model

I les altres activitats

  • Troba l'error i Cert o fals Un model escriu els documents i les afirmacions; un segon model els resol a cegues, sense saber on són els errors ni quines afirmacions són falses. Només es publiquen els que superen la verificació, i els càlculs dels contraexemples es comproven amb càlcul simbòlic.
  • Construeix el contraexemple Beta Sense cap model de llenguatge: el veredicte de cada propietat el dona el càlcul simbòlic a partir de la funció i el certificat que escrius.
  • Visualitzador Beta Els gràfics i els càlculs numèrics es fan al teu navegador, amb les funcions llegides de l'enunciat de l'exercici.
